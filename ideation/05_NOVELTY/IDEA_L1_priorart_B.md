- Closest works (3–5, more if needed): identifier — what it does — delta — does the delta matter to a referee?

  *Not on the idea card (found this session):*

  1. **arXiv:2610.09008 — "Whose Memory Is It? Scope-Aware Commit Rules for Long-Term LLM Memory" (NeurIPS 2026 workshop LP4FM) [FT].** Frames persistent memory as a "discourse ownership" problem: a proposition plus its reporting frame (assertion, belief, plan, fiction, counterfactual); a record may enter shared memory only if the actual world owns it. Cites mental spaces, DRT, CommitmentBank, speaker-commitment and event-factuality work. One of its six diagnostic prompts is literally about "frame removal". Tests generalisation to unseen reporting frames (93.44% vs 72.81% TF-IDF) and an operating point that maximises rejection subject to ≥95% admission. Method is a hidden-state probe (CASK) on Qwen2.5-1.5B/3B; data are LoCoMo answer payloads placed into single frames. States "extending ownership to nested scopes" as future work.
     — Delta: no cue-matched twins, no nesting, no quotation/self-vs-other source, no native framework writers, English only, small models.
     — Matters? **Yes, and it cuts against the card.** The card's key-insight sentence ("a memory write is a speech report whose frame has been deleted; deletion is licensed only if the path is commitment-transparent") is no longer a new framing. The measurable deltas (twins, nesting, VI) survive; the conceptual claim must be attributed and narrowed.

  2. **arXiv:2606.29279 — "Manufactured Confidence: How Memory Consolidation Turns Hearsay into Confident Facts" [FT, pp. 1, 6–9, 13–16].** Shows mem0 and LangMem rewrite hedged/attributed remarks into confident dated facts (5/5 phrasings; four extractors de-hedge 4/5–5/5); Zep keeps the modal hedge (0/12 flattened) but strips attribution (12/12) and hearsay (11/12). Decomposes cues into modality / hearsay-evidential / explicit non-verification; nine evidential markers behave non-uniformly. A hedge-preserving extraction prompt cuts wrong grants 0.45→0.10 and is reported as "targeted, not blanket over-hedging" because confident statements stay confident. Finds that an appended "unverified" tag is ignored at read time.
     — Delta: tiny n (5–12 items per cell), one fictional entity, third-party subject (not user-vs-other holder), access-control framing, no matched license/block pairs, no nesting, English.
     — Matters? **Yes.** It pre-empts "hearsay/attribution is laundered at write time by mem0/LangMem/Zep" and gives a first (weak) data point *against* C1 (a prompt fix that does not over-suppress). It also pre-empts part of C4: framed records are often not honoured at read time. A referee will ask why this is not the primary baseline.

  3. **arXiv:2609.36457 — "Memory Consolidation Flattens the Temporal Shape of User Facts" (LAPSE) [ABS + first page].** Minimal pairs of user statements differing only in aspect (progressive vs simple present); 381 pairs; 11 models; native writers of mem0, Graphiti, Letta; one-directional loss; recommends keeping the user's wording.
     — Delta: the manipulated variable is aspect, not attribution/scope; no cue-matching in the card's sense (the cue *is* the contrast); no composition; English.
     — Matters? **Partly.** "Matched-pair evaluation of native framework writers" is no longer a design novelty; the card's contribution is which contrast is paired and that the cue inventory is held constant.

  4. **ACL Anthology 2026.wmt-main.16 — "Evaluating Pragmatic Appropriateness in English–Vietnamese Machine Translation with Dyadic Profiles" (WMT 2026) [ABS].** Vietnamese person reference depends on the sender–recipient dyad; uses a prespecified *role-reversal* evaluation (same translation judged under intended vs reversed hierarchy: 20/20 appropriate vs 4/20). 30 requests, two LLMs, two native judges.
     — Delta: generation/appropriateness, not comprehension; no reported speech; no memory; very small.
     — Matters? **Yes for positioning Layer B.** The "flip the dyad, keep the string" manipulation exists in the Vietnamese LLM literature; the card's version (holder resolution under *bảo*, string-identical target, write decision) is still new, but "first to exploit dyad-anchored kin terms" cannot be claimed.

  5. **ACL Anthology 2024.sigturk-1.5 (arXiv:2406.05569) — "Do LLMs Recognize me, When I is not me: … Turkish Indexical Pronouns in Indexical Shift Contexts" [ABS]; with 2025.findings-acl.1203 (arXiv:2506.01089) — "Un-considering Contextual Information: Assessing LLMs' Understanding of Indexical Elements" [ABS].** The Turkish set (156 MCQs) tests whose "I" an embedded first-person pronoun under a report refers to — a phenomenon English lacks; GPT-4 only moderate. The English set (1,600 MCQs) finds quotation changes indexical resolution accuracy.
     — Delta: QA probes, not memory writes; Turkish morphology rather than Vietnamese kin terms; no dyad manipulation.
     — Matters? **Yes.** The card's line that Vietnamese gives "something English cannot host" has a published sibling (shifted indexicals under report in a non-English language). The direct-vs-indirect quote twins in Layer A ('Lan said, "I'm allergic…"' vs 'I said to Lan…') are close to the English indexical/quotation probe at the comprehension level.

  *Classical / adjacent-field precedents a Discourse-or-Semantics referee will expect (none is on the card except the event-factuality arXiv ids):*

  8. **J12-2002 — Saurí & Pustejovsky 2012, "Are You Sure That This Happened?" (Computational Linguistics 38(2)) [FT via PDF, first 100k chars].** De Facto: factuality profiles as source–value pairs with nested source chains (author; Mary-according-to-author), computed top-down through the dependency tree, where source-introducing predicates open new evaluation levels and polarity/modality particles update the value passed to embedded events; evaluated on FactBank (9,488 events, 13,506 event/source pairs). — This *is* a "frame calculus" with source chain, polarity and operator path. Delta: news text, author-commitment, no dialogue/user-holder, no memory decision. Matters: the card's step 1 must be presented as an adaptation, not an invention.
  9. **W06-3907 — Nairn, Condoravdi & Karttunen 2006, "Computing relative polarity for textual inference" [FT via PDF].** Recursive polarity propagation through nested factive / counterfactive / implicative / neutral complement-taking verbs with negation ("Ed didn't manage to remember to open the door"). — Direct ancestor of "commitment depends on operator class and scope order, not cue words". Delta: rule system for RTE, not an LLM benchmark.
  10. **D12-1048 — OLLIE (Mausam et al., EMNLP-CoNLL 2012) [FT via PDF]; D17-1278 — MinIE (EMNLP 2017) [ABS].** OLLIE attaches `AttributedTo` (who said/believes/doubts) and `ClausalModifier` (the if-clause) to an extraction because bare tuples "are not asserted as factual"; MinIE annotates each extraction with polarity, modality, attribution. — This is "lazy disquotation" (keep the frame with the record) fourteen years early, in Open IE vocabulary.
  11. **PMID 19435614 — ConText (Harkema et al., J Biomed Inform 2009) [ABS]; PMID 21685143 — 2010 i2b2/VA assertions task [ABS]; arXiv:2401.17602 and arXiv:2503.17425 (LLM assertion detection) [ABS, truncated].** Clinical assertion status = negated / hypothetical / historical / *experienced by someone other than the patient*, originally decided from "simple lexical clues". — The exact analogue of "fact about someone other than the user stored under the user", and the canonical cue-based policy. Delta: clinical notes, no composition twins.
  12. **2021.tacl-1.64 — Jiang & de Marneffe 2021 [ABS]** (on the card as arXiv:2107.00807, abstract-level): BERT's factuality performance comes from surface patterns and fails where pragmatics is needed. **2023.acl-short.154 — ScoNe [ABS]:** contrast sets of six examples with up to two negations where zero, one or both affect the label. **2021.eacl-main.78 — Yanaka et al. [ABS]:** composition of veridical inferences with held-out composite patterns. **D18-1501 (MegaVeridicality) [ABS], D19-1228 (Ross & Pavlick) [ABS].** — Together these already establish (a) cue reliance in factuality models, (b) scope contrast sets with nested operators, (c) held-out composition for clause-embedding verbs, in NLI/EFP form.
  13. **2025.codi-1.10 — "Zero-Shot Belief: A Hard Problem for LLMs" [ABS].** Source-and-target belief prediction on FactBank with LLMs; open, closed and reasoning models struggle; also tested on Italian ModaFact. — The nearest LLM-era result on nested-source commitment; supports the premise, not the memory claim.

- Parts of the idea already anticipated (be specific, claim by claim):

  - **Key insight, sentence 1 (write = frame deletion; licensed only if the operator path is commitment-transparent).** Anticipated conceptually in the memory setting by arXiv:2610.09008; anticipated formally by De Facto/FactBank (J12-2002) and relative polarity (W06-3907). Not new as a framing.
  - **"Operator class and scope order, not cue words."** The general thesis is established for factuality models (2021.tacl-1.64; D19-1228; ScoNe; ConText as the cue baseline). What is not established is its consequence for memory writers.
  - **Step 1, the gold tuple ⟨holder, polarity, condition, source chain, anchor, commitment⟩.** FactBank source chains; BeSt source-and-target (2022.lrec-1.262 [IDX]); MinIE annotations; committed-belief tagging (W09-3012, C10-2117 [IDX]). The six-way user-commitment label set and the rule table to a write decision appear to be new packaging.
  - **Layer A single-operator results (reported/hedged/third-party content promoted to fact by native writers).** Anticipated: AgentMemGate (plans), Manufactured Confidence (hearsay, attribution; mem0, LangMem, Zep), AuthMem-Bench (source constraints; 48/49 configurations), PASB (attribution removal 33.1%), MemAlign (attribution_confusion). The card already demotes single-operator results; this hunt confirms that is necessary.
  - **Matched-pair evaluation of framework-native writers.** Anticipated as a design by LAPSE and AuthMem-Bench; surface-matched over-detection controls by TWIST.
  - **Step 4, held-out generalisation.** Held-out *single* reporting frames: arXiv:2610.09008. Held-out compositions of veridical operators: 2021.eacl-main.78 (NLI). Held-out *combinations for memory writing*: not found.
  - **C1, partially.** That a write-time fix must be checked for over-suppression is already practised (AgentMemGate over-holding per the card; CASK@R95; Manufactured Confidence's confident-statement check; TWIST's matched controls). The specific claim — a negative block/license frontier on cue-matched twins, with a ≥20-point paired-accuracy drop — is not published. Note that Manufactured Confidence reports a prompt that helps without over-hedging (small n), which is weak contrary evidence.
  - **C3, partially.** Dyad-dependence of Vietnamese person reference tested with role reversal (2026.wmt-main.16, generation side); embedded-indexical holder under report in a non-English language (2024.sigturk-1.5); zero subject after a reporting verb mis-resolved (arXiv:2605.31056, per the card). The translate-then-extract "early choice" argument is the standard zero-pronoun-translation problem.
  - **C4 / step 5, lazy disquotation.** Substantially anticipated: OLLIE/MinIE (keep attribution and condition with the tuple); Eywa, DISCERN, True-Memory-style verbatim stores (preserve at write, decide at read); AuthMem-Bench persisted authority labels (unauthorised actions 16.9%→0.0%); Manufactured Confidence and LAPSE ("keep the user's wording"); arXiv:2608.06953 (format of the preserved stance matters). Manufactured Confidence also already shows the "errors relocate" outcome for appended tags. Only the operator-stack-typed version with read-time accounting per stack is new.
  - **"Any Vietnamese memory benchmark" as a gap.** Still a gap for Vietnamese, but non-English memory benchmarks exist (RUMBA, Russian; TimlMemBench, Chinese/English), so "first non-English" is unavailable.

- Verdict: **incremental** — reason

  The measurable core (cue-matched scope twins, held-out operator combinations, Vietnamese frame-flip pairs; claims C1–C3) was not found published anywhere I could reach, so the idea is **not anticipated**. But it is narrower than the card presents it: (i) the key-insight framing is already in arXiv:2610.09008 and is textbook FactBank/De Facto and Nairn–Condoravdi–Karttunen; (ii) write-time laundering of hearsay and attribution by mem0/LangMem/Zep is already shown in arXiv:2606.29279, alongside AgentMemGate, AuthMem-Bench and PASB; (iii) matched-pair testing of native writers exists (LAPSE, AuthMem-Bench, TWIST's matched controls); (iv) the secondary method (C4) is anticipated from OLLIE 2012 through DISCERN 2026; (v) the Vietnamese dyad manipulation has a small MT precedent at WMT 2026 and a Turkish indexical-shift sibling. A referee in Discourse/Semantics would read English Layer A as a sharper instrument for a known phenomenon, and Layer B plus the twin-dissociation and composition results as the new content. The label moves to "novel" only if the paper is positioned on C1–C3 and Layer B, cites items 1–5 and 8–12 as precedent, and drops the claim that the speech-report framing is itself the contribution. Four of the five closest works are missing from the card (2610.09008, 2606.29279, 2609.36457, 2026.wmt-main.16), which supports the card's own "highest scoop risk" note: at least ten adjacent papers appeared between June and November 2026.

  Small corrections for the card: the Chinese zero-pronoun paper now has an Anthology record (2026.findings-emnlp.654) [IDX]; TWIST's abstract reports post-adjudication κ = 0.85 on Track B v1.0 (the card's 0.565 is a raw figure I did not re-check); the Benjamins page for SLCS 211 pp. 275–300 still shows no chapter authors (URL slug ends "13ngo") — remains unverified.
