# IDEA_H2: Pairwise is not enough, truncated root lists are — the weakest sufficient provenance interface for corroboration decisions under consolidation and revocation

Evidence grades used in this card: **[notes]** = identifier appears in the project notes; **[read]** = primary record read in this session; **[listing]** = only a search/index listing seen in this session; **[pre-check]** = my own small computation in this session (`04_IDEAS/H_prechecks/h2_checks.py`), not independently reviewed.

- Gap addressed: G9 (graded source dependence, weakest sufficient interface, robustness to lineage-label errors). It also gives a provenance-side answer to the revocation theme behind G10 and touches G11 (recovery).

- Target venue and track: IJCAI 2027 Main Track (7 pages + 2 pages of references; proofs and exhaustive audits in the supplement); keywords in knowledge representation and agents/multi-agent systems.

- Problem (1 paragraph): 2610.36151 [notes; read] proves that the lineage quotient is the coarsest representation sufficient for every replication-invariant judge when lineage is a *partition* (each report has one root), and names three things as open: graded dependence, the effect of false splits and merges, and the fact that a single judge may need strictly less. 2609.01873 [notes; read] defines a ladder of side-information interfaces (reports only, authenticated root sets, derivation graph, full probabilistic model), asks for "the weakest side-information interface under which an aggregator can recover, or approximate with bounded loss, the posterior available under the full information-generating structure", and suggests privacy-preserving predicates such as pairwise root-set disjointness or bounded overlap. In agent memory the partition assumption fails as soon as consolidation writes a record from several sources and then evicts them. The question is what each surviving record must carry so that later decisions of the form "is this claim backed by at least τ independent roots" (or a posterior threshold) are the same as under full provenance, for every future set of records and after up to d sources are revoked.

- Key insight (the non-obvious observation; 2–3 sentences): Once records have several upstream roots, the independent support of a retrieved set is a weighted coverage function of root sets, so any interface that only exposes overlap facts about at most ℓ records at a time (pairwise "same source" links, disjointness proofs, similarity graphs) is subject to approximate inclusion–exclusion and leaves the support undetermined by a factor of order n/ℓ² for ℓ up to √n, however many numbers it stores. In contrast, the congruence of the decision "at least τ roots survive any ≤ d revocations" over all future contexts has exactly 1 + Σ_{j<τ+d} C(k,j) classes: a record needs only its root set truncated at τ+d, a union-mergeable label of about (τ+d)·log k bits. Sufficiency is decided by the kind of information kept (root identities up to a threshold), not by its volume.

- Approach (how the insight becomes a method/system/theory):
  - Model. Latent state Θ; roots x ∈ X (|X| = k) give testimonies that are conditionally independent given Θ, with log-likelihood weights λ_x; record r relays the testimonies of its root set R_r. With faithful relay and unanimous assertions, the full-structure log-odds of a retrieved set S is W(S) = Σ_{x ∈ ∪_{r∈S} R_r} λ_x. Decisions are thresholds on W; the counting case is |∪R_r| ≥ τ. The partition model of 2610.36151 is the case |R_r| = 1.
  - Theorem A (interaction-order hierarchy; intended statement). Let J_ℓ expose the weight of every common-root set ∩_{r∈T} R_r for |T| ≤ ℓ. For ℓ ≤ c√n there are two lineage structures on n records with identical J_ℓ whose independent support differs by a factor Ω(n/ℓ²); for ℓ ≥ C√n the support is determined within 1 ± e^{−Ω(ℓ/√n)}. Hence, for an aggregator restricted to pairwise overlap information, the smallest and largest full-structure log-odds consistent with what it sees differ by a ratio of about n/4, so its multiplicative error cannot be pushed below roughly the square root of that ratio. Proof idea: the support is a union size, and the two regimes are exactly those of Linial and Nisan, "Approximate Inclusion-Exclusion", Combinatorica 10(4), 1990, pp. 349–365 [read: Crossref record and author PDF abstract]. [pre-check] LP over Venn atoms with equal record sizes and equal pairwise overlaps: n = 4 gives 6 or 9 roots (integer witnesses: the six edges of K₄ versus one shared root plus two private roots per record), n = 6 gives 20 to 40, n = 12 gives 924 to 3234; the ratio is (n+2)/4 for these symmetric families.
  - Theorem B (coarsest mergeable statistic; intended statement). For k ≥ τ+d, call R and R′ equivalent if for every future root set U and every revoked set D with |D| ≤ d the decisions |(R∪U)∖D| ≥ τ and |(R′∪U)∖D| ≥ τ coincide. The classes are the singletons {R} with |R| < τ+d and one class containing all larger sets. So the (τ+d)-truncated root set is the coarsest statistic that is sufficient for all futures and commutes with union; it needs ⌈log₂(1 + Σ_{j<τ+d} C(k,j))⌉ bits per record and no fewer. Corollaries: (i) a strict coarsening of the root-set interface for a single judge, which makes precise the remark in 2610.36151; (ii) a separation between one-shot sufficiency (one bit for a fixed S) and sufficiency over all futures (Θ((τ+d)·log(k/(τ+d))) bits), which is an instance of the recurrent-sufficiency question left open in 2606.09858 [notes]; (iii) the storage price of revocability is additive, d extra root identifiers per record. Proof idea: a right-congruence argument of the kind used for minimal automata; to separate R ≠ R′ with |R′| < τ+d, pick x ∈ R∖R′, a context U ⊇ R′ avoiding x and a deletion set that leaves exactly τ−1 roots. [pre-check] Exhaustive enumeration for k ≤ 6, τ ≤ 3, d ≤ 2 gives exactly the predicted class counts (for example 43 classes for k = 6, τ = 2, d = 2); keeping the τ+d smallest root identifiers answered 20,000 random threshold-after-revocation queries without error.
  - Theorem C (budgeted approximation). If (1±ε) accuracy with failure probability δ per query is enough, mergeable distinct-count sketches give labels whose size does not grow with |R_r|. This is a corollary of the distinct-elements literature (Kane, Nelson, Woodruff, PODS 2010 [listing]); its role here is the contrast with Theorem A: fewer bits, bounded loss.
  - Theorem D (graded dependence, restricted). If record r relays root x through an independent binary symmetric channel with log-odds fidelity κ_{rx}, the unanimous-assertion log-odds is W(S) = Σ_x g_x(Σ_{r∈S, x∈R_r} κ_{rx}) with g_x(s) = log[(q_x + (1−q_x)e^{−s}) / ((1−q_x) + q_x e^{−s})], increasing, concave and bounded by λ_x. The sufficient mergeable label is a root-indexed fidelity vector with addition as merge; faithful replication is the limit κ → ∞ and independence is the linear regime. I derived g_x and its concavity by hand in this session; it is the binary analogue of the shared-root information ceiling in 2609.01873.
  - Theorem E (label errors; named open in 2610.36151). If each record–root incidence is independently relabelled as a fresh pseudo-root with probability η (provenance laundering, the failure named by PPMF 2607.29167 [notes]), the observed count exceeds the true count by Σ_x (η·m_x − η^{m_x}) in expectation, where m_x is the number of records carrying root x: zero for unreplicated roots, linear in replication otherwise. A τ-rule is therefore safe only against replication budgets m with P(Bin(m, η) ≥ τ−1) small, and (true count, η) are not jointly identifiable from label multiplicities alone, which is a graded version of the information boundary (Theorem 1) of 2610.36151. False merges lose at most one root per merged pair. The asymmetry gives the minimax-regret correction to τ.
  - Boundary case most likely to break it: Theorem D beyond stars. When a record is derived from another record, relay noise is shared along the path, records are no longer conditionally independent given the root testimonies, and per-record additive labels stop being sufficient; the result must then be stated for trees with belief propagation or restricted to depth-one derivations. A second boundary: Theorem B assumes root identities are comparable across records (a shared naming authority); under renaming by an adversary the label must be authenticated.

- Contribution type: new theory/bound (characterisation plus separation), with a small negative result for pairwise provenance graphs.

- Claims (falsifiable, 2–4):
  1. For every n ≥ 3 there are record families with identical sizes and identical pairwise overlaps whose independent-root counts differ by a factor (n+2)/4; refuted by an LP or enumeration showing a smaller maximal ratio.
  2. The number of context-equivalence classes for threshold τ under d revocations is 1 + Σ_{j<τ+d} C(k,j); refuted by one pair of distinct sub-threshold root sets that no context separates, or by a coarser statistic that still answers all queries in an exhaustive universe.
  3. At equal bits per record, truncated root lists make zero decision errors while pairwise-overlap graphs, single family identifiers (as in FPA, 2610.17763 [notes; read]) and content deduplication each err on a non-negligible share of reachable states of consolidated memories; refuted if on memories produced by real consolidation pipelines the pairwise interface errs on fewer than about 1% of τ-corroboration queries (then Theorem A is a worst case with no practical bite).
  4. With η measured on a real pipeline, the inflation formula of Theorem E predicts the replication level at which a τ = 2 rule flips, within sampling error.

- Closest work known so far (with identifiers) and the expected delta:
  - 2610.36151 [notes; read]: partition lineage, coarsest representation for the whole judge class, audits on 28,224 stars and 2,052 DAGs. Delta: set-valued lineage, task-indexed truncation with a minimality proof, revocation, label noise.
  - 2609.01873 [notes; read]: interface ladder that already contains authenticated root sets; Gaussian shared-root ceiling; names the weakest-interface problem. Delta: a lower bound for bounded-order overlap interfaces, including the pairwise predicates it suggests, and an exact minimal interface for threshold decisions.
  - 2610.25865 [read]: minimum-cost evidence certificates for Horn conclusions that survive withdrawal of at most k source domains; transversal characterisation; shows disjoint-proof counting is incomplete; coNP/NP-completeness. It selects records for one query; it does not characterise per-record sufficient statistics, interfaces or sketches. The τ+d threshold in Theorem B is the same combinatorial fact in its simplest instance and must be cited.
  - 2605.10870 (DeMem), 2606.09858 [notes]: decision-sufficient compression without a source structure. Bonet and Geffner, JAIR 2014 and provenance semirings (Green et al., PODS 2007) [notes]: the classical comparators a KR referee will raise.
  - Strongest result a referee will compare against: Theorems 2–3 of 2610.36151 (coarsest invariant-complete representation) and, for the lower bound, Linial–Nisan itself.
  - Honest status: Theorem A is a direct corollary of Linial–Nisan; Theorem C of distinct-elements sketching; Theorem B is new as far as my searches go but elementary (a congruence computation); Theorems D and E are short calculations. The contribution is the characterisation as a whole and its answer to two named open problems, not a hard proof.

- Evaluation sketch: settings, baselines (strongest first), metrics, decisive experiment
  - Settings: (i) exhaustive universes (all set systems with n ≤ 5 records and k ≤ 6 roots, all contexts and revocation sets), in the style of the exhaustive audits of 2610.36151; (ii) consolidated memories built with the four frameworks used by Memory Echo (A-MEM, Mem0, CoM, LangMem) on public QA data, with ground-truth root sets recorded by instrumentation; (iii) the 277 AVeriTeC-derived profiles used by 2610.36151, extended with multi-source summaries.
  - Baselines, strongest first: full root sets; lineage-quotient family identifiers; compiled or factored encodings of the full dependency structure at equal bits; pairwise overlap graphs; content deduplication; raw occurrence counting.
  - Metrics: decision-equivalence rate with the full-provenance oracle over (state, future context, revocation) triples; bits per record; worst-case and average support error; error under injected label noise.
  - Decisive experiment: the exhaustive audit. If a statistic strictly coarser than the truncated root set answers every query, Theorem B is false; if a standard compiled representation reaches the same bits and the same equivalence, the result should be presented as a knowledge-compilation corollary and the paper's claim reduced to Theorems A and E.
