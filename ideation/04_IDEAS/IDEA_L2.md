# IDEA_L2: The Third-Person Bottleneck — agent memory as a homogenising channel for Vietnamese person reference and regional forms

- Gap addressed: G12 (ACL 2027 special theme × agent memory).

- Target venue and track: ACL 2027 via ARR — Special Theme "Homogenization and knowledge collapse in LLMs" (the call names cross-linguistic homogenization including lower-resource languages, metrics, mechanisms, human-vs-model diversity). Fallback areas: "Multilingualism and Cross-Lingual NLP", "Dialogue and Interactive Systems".

- Problem (1 paragraph): Persistent memory is sold as the component that makes an assistant *more* specific to each user. In Vietnamese, the most pervasive user-specific signal is not a fact at all: it is the xưng–hô pair, i.e. how the user refers to themself and to the assistant (anh–em, chị–em, cháu–cô, con–…, tớ–cậu, tôi–bạn), chosen again on almost every clause, together with regional forms for kin and for particles (má / mẹ, ba / bố, vô / vào, nha / nhé). A fluent reply cannot be produced without choosing a pair. Memory writers, however, emit third-person propositional records ("User moved to Ho Chi Minh City; user's mother lives in Can Tho"), a genre that has no place for the dyad. The suspected result is that, after the session boundary, every Vietnamese user is answered in the same unmarked tôi/mình–bạn frame with standard kin lexemes, while fact-recall scores stay perfect — a homogenization that today's memory benchmarks (QA accuracy on stored facts) cannot see and that content-diversity benchmarks explicitly exclude (MemBubble filters out style and formatting preferences).

- Key insight (the non-obvious observation; 2–3 sentences): Languages differ in what they *must* express (Jakobson's observation about translation): Vietnamese obliges every act of self- and addressee-reference to encode the relation between the two interlocutors, and that information lives only in the form of first- and second-person terms — exactly the tokens that a memory writer rewrites when it converts dialogue to third-person records. The loss is therefore structural rather than a matter of record language (it should survive "write memories in Vietnamese"), invisible to fact-level evaluation, and directional (collapse to the unmarked pair and to the majority lexical variant when synonymous entries are merged). A second consequence follows from reciprocity: keeping the frame is not string copying, since the agent must produce the *converse* of the user's pair (user "anh … em" → agent "em … anh"), so a stored note of the user's wording does not by itself restore correct behaviour.

- Approach (how the insight becomes a method/system/theory):
  1. Probe set. Natively authored multi-session user scripts in Vietnamese crossing: xưng–hô frame (about 12 pairs, including marked ones such as cháu–bác, name-as-self-reference, intimate tớ–cậu), region (Northern / Central / Southern lexicon and particles), and frame dynamics (stable; shifts mid-history toward intimacy; shifts toward distance). Each script carries a few ordinary facts so that fact recall can be scored on the same runs. Illustration: session 1 user "Anh mới chuyển vô Sài Gòn, má anh vẫn ở Cần Thơ. Em nhắc anh gọi cho má mỗi tối Chủ nhật nha."; later-session reply that keeps the frame: "Dạ anh, tối nay anh nhớ gọi cho má nha."; collapsed reply: "Chào bạn! Bạn nhớ gọi cho mẹ tối nay nhé." [regional markers to be validated by native annotators from the relevant regions].
  2. Channel conditions at a fixed backbone and fixed follow-up query: T = full transcript in context; M = framework's native memory; M-vi = same, records forced to Vietnamese; M-1p = records forced to keep the user's first-person wording verbatim; M-k = memory after k rounds of consolidation / merge (k = 1, 2, 3); 0 = no memory. English control scripts (where no such obligatory category exists) run through the same conditions.
  3. Closed-class measurement. Person-reference terms, kin lexemes and sentence-final particles are closed classes, so the main metrics are computed by lexicon rules and validated by annotators on a sample, with no LLM judge on the primary endpoint.
  4. Mechanism localisation. Inspect the stored records: does any record encode the pair, in which person, in which language; which merge/dedup operation replaced a regional variant by the standard one.
  5. Minimal mitigation, tested not sold: a dyad record ⟨user self-term, user's term for agent, licensed converse pair, evidence span, last-updated⟩ with supersession on frame shift, plus verbatim retention of kin lexemes.

- Contribution type: new measurement/benchmark + mechanism analysis (theme-track empirical paper); the mitigation is a secondary system contribution.

- Claims (falsifiable, 2–4):
  - C1 (locus). At identical backbone and follow-up prompt, the frame-retention rate under native memory (M) is lower than under full transcript (T) by a margin exceeding the script-clustered 95% interval, and the cross-user entropy of the agent's address pairs under M is closer to the no-memory condition than to T. Refuted if T also collapses (then the base model, not the memory channel, is the homogeniser) or if M retains the frame.
  - C2 (structure, not language). M-vi does not recover retention, whereas M-1p recovers part of it; and even M-1p under-performs the dyad record on frame-shift scripts because the converse pair must be computed and updated.
  - C3 (ordering and invisibility). Loss is ordered address frame > regional kin lexeme for third parties > sentence-final particles ≥ propositional facts ≈ 0; fact-QA accuracy does not differ between M and the dyad-record condition. Refuted by any other ordering or by a fact-QA cost.
  - C4 (direction and generational decay). Errors go to the unmarked pair and to the Northern-standard lexeme rather than to random alternatives, and retention decreases monotonically with consolidation depth k.

- Closest work known so far (with identifiers) and the expected delta:
  - MemBubble, arXiv:2610.25127 (read in part in this session: abstract, introduction, dataset overview) — 1,000 instances from real conversations; memory lowers response entropy by 34.7% relative to full history; preferences about style and formatting are excluded; dialogues span 35 languages but with no linguistic analysis. Delta: form-level, language-specific diversity; a grammatical reason for the loss; consolidation-depth factor; Vietnamese.
  - "Artificial Hivemind" (NeurIPS 2025 best paper, OpenReview saDOrrnNTz) and "The Multilingual Artificial Hivemind", arXiv:2610.16755 (abstract-level: 23 open models, 13 languages, homogenization gap tracks competence). Delta: these measure model-level output similarity; we isolate a system component (memory) as a mechanism at fixed model.
  - BanglaSocialBench, arXiv:2603.15949 (read in this session: 1,719 native-written instances, 12 models, systematic over-formality in address pronouns). Delta: static single-turn choice there; here continuity of an established dyad across sessions and through memory.
  - Culturally specific kinship generation, arXiv:2609.26942 (read in this session: Hindi, Tamil, Korean; selection ≫ generation); Bengali honorific allocation, arXiv:2610.14769 (abstract-level; the "English has no such signal, so the system must choose" argument for translation). Delta: no memory, no Vietnamese; our argument transfers the obligatory-category point from translation to memory writing.
  - VialectBench, arXiv:2608.10414 (abstract-level: 400 standard items, 2,400 human dialect rewrites, robustness of *understanding*). Delta: we test whether the agent *gives back* the user's variety after memory.
  - OP-Bench, ACL Anthology 2026.emnlp-main.1168 (its limitations concede English-only and culture-dependent norms); "Harness the Memory", arXiv:2608.15008 (62% of memory-benchmark usage falls on two dialogue datasets, LoCoMo and LongMemEval). Delta: evidence for the blind spot.
  - Index-only leads to read before writing: FAVoR arXiv:2609.30968 (author-style homogenization in federated personalization), "Aligned but Flattened" arXiv:2609.00565, "Alignment by Stereotyping" arXiv:2609.05993.
  - Linguistic grounding: Luong (1990), John Benjamins (record fetched). Jakobson (1959) "On Linguistic Aspects of Translation" was seen only in a search listing — verify before citing.
  - Not found: any study of person-reference or register continuity through agent memory, in any language (two alphaXiv queries; not an exhaustive search).

- Evaluation sketch: settings, baselines (strongest first), metrics, decisive experiment
  - Size: about 360 Vietnamese user scripts (12 frames × 3 regions × 10 authored variants) + 60 frame-shift scripts + 100 English control scripts; 5 follow-up probes each ≈ 2,600 scored responses per configuration. Configurations: 3 memory frameworks × 3 backbones × the channel conditions above for a core subset → about 20 system configurations in the main table.
  - Baselines, strongest first: (1) native memory plus an explicit system instruction "address the user as they address themselves; store how the user wants to be addressed" (the fix a product team would try first); (2) M-1p verbatim first-person records; (3) T, full transcript (upper reference for what the backbone can do); (4) human reference: native annotators answering the same follow-ups from the same history (also yields the human diversity figure the theme asks for); (5) no memory.
  - Metrics: frame-retention rate (agent pair = licensed converse pair); default-collapse rate; diversity ratio = entropy of agent pairs across users ÷ entropy of licensed pairs; regional round-trip rate for kin lexemes and particles; frame-update latency on shift scripts; annotator-rated appropriateness and direction of violation (under-respect vs over-distance) on a stratified sample with κ; fact-QA accuracy as the "invisible to standard benchmarks" control.
  - Decisive experiment: T versus M at fixed backbone and prompt on the stable-frame scripts. The insight predicts a large retention gap and near-identical fact QA. Either "T collapses too" or "M retains" falsifies the locus claim.

- Resources needed vs available (00_CONSTRAINTS.md): commercial APIs for backbones and frameworks — available; one open backbone on 1–2 GPUs — available; ≥2 native Vietnamese annotators for authoring, lexicon validation and the human reference — available, with one caveat: authentic Central and Southern forms need authors or checkers from those regions (to confirm who the annotators are).

- Risks and unknowns:
  - "Obvious" objection: a referee may say fact memories were never meant to store style. Answer built into the design: in Vietnamese this is grammar, not style; the loss is quantified against a human reference; C2–C4 are non-trivial predictions.
  - Some frameworks may already keep first-person wording or a "how to address the user" note. The extraction prompt of the third-party `mem0-rust` crate (docs.rs source page fetched in this session) tells the writer to use first person for user information; whether Mem0's own Python prompt does the same, and what first-person form a writer picks in Vietnamese, was not verified. This is an experimental factor, and it may shrink C1 for that framework.
  - Narrowness: one language. The theory predicts the same for languages with obligatory honorific or T–V choice (Korean, Japanese, Bangla); without annotators these stay as stated predictions.
  - Regional lexicon claims (má/mẹ, ba/bố, vô/vào, nha/nhé) are standard textbook contrasts but real usage is mixed; scripts must be validated by speakers of each variety.
  - Vendor built-in memory features cannot be driven reproducibly through APIs; the study is limited to open frameworks and API-level memory tools.

- Conference core / journal extension (1 line each):
  - Conference core: the T-vs-M retention gap, the ordering and direction results, the consolidation-depth decay curve, and the human reference, for Vietnamese with an English control.
  - Journal extension (Computational Linguistics or JAIR): additional obligatory-deixis languages, longitudinal user simulation of frame negotiation, and a learned frame-tracking writer evaluated against the rule-based dyad record.
