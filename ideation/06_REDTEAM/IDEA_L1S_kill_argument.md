# Kill argument for IDEA_L1S (same-family reviewer, provisional; 2026-11-20)

**Recommendation: reject. Memory does no explanatory work in this paper, and without it what remains is a small single-language deixis probe.**

The information-matched protocol, introduced to repair the predecessor's true-by-construction result, holds constant every memory-specific factor (bounded window, consolidation, retrieval), so none of them can explain the outcome. What is left is one LLM call reading one Vietnamese passage under an English prompt. C1 then contrasts kin-term items with explicit-name controls, but kin-term items are harder for any reader, so larger divergence there shows difficulty, not that "English-designed writers have no instruction for the step". That causal claim rests entirely on baseline 2, the Vietnamese dyad-resolution instruction, and both of its outcomes sink the paper. If the instruction closes the gap, the contribution is a one-line prompt patch for Mem0, Graphiti and LangMem. If it does not, the failure belongs to the backbone, and the result is a sibling of Turkish indexical shift (2024.sigturk-1.5) and Chinese zero pronouns (2026.findings-emnlp.654) wrapped in an extraction format. The downstream read-out is, by the card's own admission, not novel.

The card confirms the weakness itself: each refutation is pre-converted into a repositioning (C1 dead: "framework-native writers and Study 0"; C4 rare: "diagnostic study"), so no outcome counts against the submission. A Discourse referee will ask for the comprehension benchmark without the memory wrapper; an Agents referee will ask what a memory designer learns beyond "localise your prompt". Neither gets an answer.
